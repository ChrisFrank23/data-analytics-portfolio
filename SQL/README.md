## 📌 Project Overview

This project explores global COVID-19 data using SQL to analyze trends in cases, deaths, and infection rates across different countries and regions.

---

## 🎯 Objectives

- Analyze total cases and deaths over time  
- Calculate death percentage and infection rates  
- Compare countries based on COVID-19 impact  
- Identify global trends  

---

## 🛠️ Tools Used

- SQL (Data Exploration & Analysis)

---

## 🔄 Process

1. Data Cleaning  
2. Data Aggregation using GROUP BY  
3. Use of JOINs to combine datasets  
4. Creation of calculated metrics (death rate, infection rate)  
5. Use of Window Functions for advanced analysis  

---

## 📊 Key Insights

- Significant variation in death rates between countries  
- Rapid growth patterns during early pandemic stages  
- Some countries experienced higher infection rates relative to population  
- Global trends show waves of infection over time  

---

## 🚀 Conclusion

This project demonstrates strong SQL skills, including data aggregation, joins, and advanced functions to analyze real-world data.
