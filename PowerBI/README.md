# 💼 Data Professional Survey Analysis (Power BI Project)

---

## 📌 Project Overview

This project analyzes survey data from professionals in the data industry, exploring trends in salary, job roles, demographics, and work conditions.

---

## 🎯 Objectives

- Analyze salary distribution across roles  
- Understand demographic trends (age, gender, region)  
- Identify patterns in job satisfaction and career paths  
- Visualize insights using an interactive dashboard  

---

## 🛠️ Tools Used

- Power BI  
- Power Query  
- Data Cleaning & Transformation  

---

## 🔄 Process

1. Data Cleaning using Power Query  
2. Data Transformation and structuring  
3. Creation of calculated fields  
4. Dashboard development with interactive visuals  

---

## 📊 Key Insights

- Salary varies significantly by role and experience  
- Certain regions show higher average salaries  
- Job satisfaction differs across positions  
- Demographics influence career progression
