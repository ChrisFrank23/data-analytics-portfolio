## 📌 Project Overview

This project analyzes HR data to uncover insights about employee distribution across gender, location, diversity, and workforce trends over time.

---

## 🎯 Objectives

- Analyze employee distribution
- Understand workforce growth trends
- Evaluate remote vs on-site work
- Explore diversity within the company

---

## 🛠️ Tools Used

- SQL
- Power BI

---

## 🔄 Process

1. Data Cleaning using SQL  
2. Data Transformation  
3. Dashboard creation in Power BI
